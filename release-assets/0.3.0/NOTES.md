## 下载与安装
在下方 **Assets** 下载 `course-compass-0.3.0-android.apk`。适用于 Android 8.0 及以上。

已有课间旧版：**直接覆盖安装，不要先卸载**。本版沿用原包名和签名，保留本机课表、成绩、壁纸与设置。清理应用数据或卸载会造成数据丢失。

## 0.3.0 更新
- 新增任意学校通用模式：CSV、Excel 复制表格及课程 JSON 导入，确认预览后更新。
- 新增自定义学校入口；同结构正方教务接入为试验功能，各校自动同步仍需单独适配。
- 新增可拖动贴纸、留言、倒数日和 HTTPS 快捷入口。
- 新增玻璃、像素、唱片风格课程卡片，可选择课程、日期或一句话。
- 支持 iPhone 的应用内网页体验；本 Release 没有原生 iOS 安装包或 WidgetKit 锁屏扩展。

## 验证范围
通过 49 项本地自动检查、60 个弹层关闭/返回场景、Chromium 与 Windows WebKit 交互检查及旧版资源升级数据保留模拟。安装包已签名，全部 224 个内置网页资源完成完整性核对。尚未连接 Android/iPhone 真机验收，新学校的自动同步也未完成实校验证。
