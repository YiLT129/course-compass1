# 0.7.1 · 更轻的切页和弹窗

- 底栏改用滑动选中条与短幅页面过渡；快速切换会取消上一个过渡。切页保留各自的滚动位置，再点当前标签可回到顶部。
- 切页不再重建课表和今日清单。换周、显示周末只更新周课表与上课状态；原课表、节次和外观设置不变。
- 弹窗的拖拽区域更容易触达；短拉松手回弹，长拉或快速下拉可以关闭。保留关闭按钮、背景点击、系统返回和嵌套界面；退出过程中阻止误提交。
- 实时玻璃模糊主要留在顶栏、底栏，移动的弹窗使用轻量半透明底色。系统启用减少动态效果时，缩短交互路径并关闭动效。
- 保留自定义壁纸、课块透明度、七天同屏、拖调和日程提醒。

验证：124 项 Node 自动检查通过；Chromium 和 Windows WebKit 验证滚动保留、七天同屏、嵌套返回、拖动及减少动效，并回归日程弹窗。90 门模拟课程下，Chromium 连切三个标签的同步处理时间中位数约 34ms → 12ms；这是测试环境的处理时间，不代表所有设备的帧率。未在安卓真机上验证手感。
