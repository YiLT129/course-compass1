# 0.5.1 · 按课间间隔显示连堂课

- 修正课块分组：同一排课中，连续小节之间休息不超过10分钟时合并显示；超过10分钟就分成不同课块。按用户已保存的学校作息计算，不硬编码两小节一组。
- 左侧12节的编号、上下课时间与原始导入记录保持原样；周课表、今日安排、外观预览与分享海报使用同一分组规则。
- 合块显示“第1–2节”等范围，第二小节上课时仍高亮整块；当前课程和锁屏/桌面课程时钟继续按真实小节判断，课间不会误报为上课。
- 连堂详情可选择其中一个小节修改教室或停课。不同教室、停课或本次调整状态会分开显示，恢复后自动重新合并。
- 保留课程配色、字号、密度与七天同屏；沿用原包名和原签名，版本0.5.1（18），可直接覆盖安装，勿先卸载。
