# 0.6.0 · 更轻的课块与离线小工具

- 课块更紧凑：旧默认每小节84px改为68px，左侧原有节次编号和钟点不改；大字号仍自动留出必要高度。已手动定制的密度保持原值。
- 背景更透明：旧默认84%不透明度改为58%，滑块可调到20%；自动清晰模式不再强制整张课块接近不透明，仅对课名、教室与节次文字加局部底衬。自定义透明度继续保留。
- 截图离线导入：内置中英OCR资源，支持选择图片、校准课程区域/星期列/节次、修改识别草稿、核对后进入现有导入预览。只更新所选周次和截图覆盖区域，保留其他周及未截到的课程。
- 长按拖动调课：将一个课块放到同周另一天/节次，核对后选择只改这一次或后续已排周；详情也有操作入口。冲突需要确认，越界不能保存，可恢复学校安排。
- 离线课表对照：导入一份朋友的JSON课表，按实际日期和双方各自作息显示共同未排课时间；不需要账号或服务器，也不覆盖自己的课表。
- 大字教室卡：显示当前或下一节教室，可切换今天/明天及课程；Android长按应用图标提供快捷入口，网页也保留直接入口。
- 本地抽签盒：自建多个列表、逐行添加选项、去重、抽一个、删除和清除结果，重启保留。
- 完整备份纳入调课、朋友课表和抽签列表，主题分享排除这些私人记录；新增界面复用返回、关闭及遮罩处理。

继续沿用包名 cn.coursecompass.app 和原签名。版本0.6.0（19），最低Android8。请直接覆盖安装，不要先卸载。

验证：117项自动数据/采集器/备份检查通过；Chromium与Windows WebKit完成截图中文识别、调课、对照、抽签、大字教室和透明度/密度检查；真实触摸事件检查长按调课。全新PWA缓存后、断网且首次初始化引擎的中文识别通过。真实0.5.1资源覆盖升级的原图/裁剪图校验值及私人数据保持；默认迁移和自定义外观保留分别检查。原始课表保持、部分区域/单周导入保护、原证书与内置资源核对用于交付。

限制：截图识别准确率受清晰度、颜色和布局影响，须校准并逐条核对；单色或不规则表格可能需要手动调整节次。网页版首次访问仍需下载本机识别资源，安装或缓存完成后可离线使用。朋友课表不是实时在线状态，调课后需重新导入。同步重建ID时，调课只在来源候选唯一时回退匹配，存在歧义的记录保留但不擅自移动另一门课。Android快捷入口是否显示由启动器决定。尚未连接Android或iPhone真机；iOS仍为主屏幕网页，没有签名IPA或原生WidgetKit。大图识别耗时取决于设备性能。
