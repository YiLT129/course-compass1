# 0.8.0 · 日程周历与安卓提醒

- 底栏新增「日程」：周一到周日同屏，数字标记各天的日程数量。点日期查看按钟点排序的卡片，可切周、跳到指定日期、回今天或跳到下一条日程。
- 安卓保存后登记系统闹钟。前台弹窗获得渲染机会后才确认；应用不在前台，或没有及时确认时，改走系统通知。精确日程、普通后备和弹窗补发分开调度；打开准点提醒时，系统可能显示闹钟图标。
- 新增「1 分钟测试通知」。状态显示闹钟登记、唤醒和系统投递，并区分后台触发、应用打开时触发和重新打开补发。测试不写进日程、课表或备份。
- 已有日程和课表保留。安卓日程与提醒队列一起落盘，避免重开时被旧网页缓存覆盖。完整备份恢复保留失败后重试的记录；过期日程只保留历史。

验证：124 项 Node 自动测试、JVM 调度与补发检查、Chromium 和 Windows WebKit 周历与弹窗、安卓桥模拟、触摸调课。仍未在 iQOO 真机验证划掉最近任务后的通知；系统勿扰、省电或强行停止仍可能影响送达。网页版仅打开时弹窗。

Android 8 起，版本 0.8.0（22），沿用包名和原签名，直接覆盖安装。
