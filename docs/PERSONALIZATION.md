# 个性化与数据迁移

菜单 → 课表挂件：贴纸、留言、倒数日和HTTPS快捷入口。最多20个；坐标按比例保存。进入编辑后可以拖动、缩放、旋转、前移后移、锁定、撤销重做及自动对齐。右下角✓或系统返回完成编辑；平时点击不会误移动。隐藏不会删除挂件。

菜单 → 主题与分享：预设主题、本机主题库（最多8套）、导入和导出主题包。主题仅包含裁剪壁纸、颜色、字体、透明度、贴纸和组件风格，不带课程、成绩、身份信息、私人留言、倒数日或链接。应用主题保留个人记录和周末偏好。

菜单 → 完整备份与恢复：导出课程、个人安排、原图和裁剪图、挂件、外观设置、主题库、学校设置，以及已保存的成绩与姓名学号。恢复前先展示内容摘要，确认后替换本机数据；图片和设置失败时一起回滚，意外关闭后重启继续恢复。文件最多64MB，不含学校Cookie、登录凭据或系统权限。完整备份含私人信息，请自行保管。

菜单 → 分享课表图片：简洁、壁纸和像素风格；默认隐藏教师、教室与个人安排，可以分别选择加入。姓名、学号、成绩和课表上的私人挂件不会画入海报。生成1080像素宽PNG；安卓可直接分享或保存。

菜单 → 课程卡片与锁屏提示：玻璃、像素、唱片风格，支持课程、时间日期或一句话、主题色与透明度。Android每一个桌面组件右侧有「设置」，可独立保存配置；应用内卡片和通知使用默认设置。跨设备恢复不会自动添加系统组件；先添加组件，再从保存的配置中复制外观。锁屏通知由系统决定外观。

iPhone/iPad：Safari主屏幕网页支持应用内效果、壁纸、备份、主题和文件导入。网页不能注册原生WidgetKit锁屏组件；没有签名IPA，也未在iPhone真机验证。

菜单 → 版本与更新：查询本项目GitHub Releases，区分正式与预览版本，展示校验值。安卓包下载后覆盖安装；iPhone隐藏APK下载。有等待中的网页更新时可点击更新并重新打开，不强制刷新正在编辑的页面。

一周课表、今日安排和分享海报按单个节次展示。页面上方会按设备当前日期时间及已保存作息展示正在上课、课间或下一节；当前课块高亮。前台按分钟及上下课边界更新，后台停止计时，重新回到应用时刷新；不请求网络授时。请在「学期与作息」核对学校实际钟点。显示拆分不会修改原始排课，完整备份和学校同步继续使用原记录。

## 0.5.0 外观与单次修改

外观与壁纸提供七天预览、紧凑/舒展预设、课名字号、每节高度、间距、按课程配色，以及贴纸/主题快捷入口。高度会按字号留出必要空间，避免文字被卡片裁掉。自动可读性分析照片明暗和复杂度，在本机调整时间底衬、卡片与局部模糊，可随时关闭。课程配色和胶囊展开状态保存在本机；主题包只分享通用外观与贴纸。

当前课程胶囊默认收起，点开看教室、具体时间和下一节；可从这里打开实际日期的课程详情，展开偏好会保存。

点开某周某节课 → 仅修改这一次：可改教室、标记这节停课、恢复教务安排。记录按学校、学期、日期、节次和课程特征隔离；学校重新导入产生新ID时仍能匹配，无法匹配的标记保留。停课只表示你在本机设置的状态，不会修改学校系统。课程目录未选具体日期时不会提供单次修改入口。原生课程快照跳过停课项，教室同步使用本机有效安排。

## 本机恢复与导入撤回

每次新版本首次启动，在迁移设置前保存一份升级前本机完整恢复点；应用内点下载安装包或切换等待中的网页更新前也会保存。仅保留最近一份，首次安装没有已有数据时不会产生空恢复点。「完整备份」可导出、预览后恢复；本机空间不足时会说明失败，不假装已保存。卸载或清除数据仍会丢失本机恢复点。

最近5次课表确认导入显示新增、移除与相同记录数，可撤回最近一次导入。撤回前再次确认，只恢复学校课程，不覆盖壁纸、个人安排、留言、单次修改；导入后手动改过的作息保留。切换学校或课程已被其他操作改动时拒绝直接撤回，保留当前数据。完整备份包含导入撤回记录，主题包排除它们。

0.5.1：课块按已保存作息的课间分组，不超过10分钟合并、超过10分钟分开。左侧时间仍按小节显示；详情可选择合块中的一个小节做单次调整。
