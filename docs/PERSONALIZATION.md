# 挂件与小组件

菜单 → 课表挂件：贴纸、留言、倒数日和HTTPS快捷入口。最多20个，坐标按比例保存。点拖动摆放后可以拖动；右下角✓或系统返回完成编辑。父菜单会同时关闭，让课表可操作。关闭或隐藏不会删除挂件；单项删除后自动保存。

菜单 → 课程卡片与锁屏提示：玻璃、像素、唱片风格；当前或下一节课程、时间日期、一句话。点击保存后写入本机，Android快照会同步。所有Android桌面组件当前共用同一套设置。应用内卡片可单独关闭，挂件可一键隐藏。锁屏通知不播放铃声，外观由系统控制。

iPhone/iPad：Safari主屏幕网页支持上述应用内效果、壁纸与文件导入。网页不能注册原生WidgetKit锁屏组件；没有签名IPA，也未在iPhone真机验证。原生iOS扩展未来需Xcode、签名与App Group共享课表，不能仅靠CSS实现。

本地存储：personalization.v1保存挂件与卡片，不包含学校账号。壁纸位于IndexedDB。清理网站数据或卸载可能丢失数据；目前课表备份只导出课程与作息，不包含壁纸与挂件。
