# 0.5.0 · 更顺手的个人课表

- 课表密度：字号、每节高度和课块间距分别可调，提供紧凑/舒展预设，七天保持同屏。
- 当前课程胶囊：默认一行收起，展开显示教室与下一节，记住展开偏好；时钟改为分钟与上下课边界更新，后台停止刷新。
- 壁纸可读性：本机取样明暗与复杂度，自动调整文字底衬、卡片清晰度和局部模糊；保留手动开关。
- 单次修改：仅修改所选日期的一节教室或停课，可恢复教务安排；不会改写学校原始课表，再次同步后保留本机标记。
- 外观实时预览与课程独立配色，贴纸/主题入口集中；课程颜色等私人配置不进入分享主题包。
- 升级恢复点：新版本首次启动时、迁移设置前、应用内下载更新前保存一份本机完整恢复点，可导出或预览恢复。
- 导入历史：最近5次变化摘要，支持确认后撤回最后一次课表导入；保留个人安排、壁纸、留言、单次修改与导入后手动作息。

沿用原包名、签名和本机数据来源，直接覆盖安装，不要先卸载。最低Android8，版本0.5.0（17）。本机恢复点无法代替导出备份，卸载/清除数据仍会删除它。

浏览器与原生桥模拟检查不替代手机真机验收；系统组件与锁屏刷新仍受启动器、权限和省电策略影响。iOS仍为主屏幕网页，无签名IPA或原生WidgetKit。

验证：86项数据/采集/外观/备份自动检查、15项原生时间检查和76个弹层返回场景通过；Chromium/Windows WebKit外观、同屏贴纸与恢复流程通过，真实0.4.1资源覆盖升级保持原图与私人数据。安装包242份资源逐字节核对，沿用原证书。
