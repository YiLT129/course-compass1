# UI 动效 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans. Steps use checkbox syntax.

**Goal:** 让课间切页、滑周与弹窗响应更快。
**Architecture:** 页面导航只切换已渲染区块；周次更新局限到课表。弹窗仍用共享导航模块；现代版启用可取消的位移动画并限制移动层模糊。
**Tech Stack:** ES modules, CSS, Web Animations, Playwright.
**Spec:** docs/superpowers/specs/2026-11-12-ui-motion-design.md

- [ ] 用真实浏览器检查旧版点击底栏会替换课表和丢滚动位置。
- [ ] 在 `dist/demo/demo.js` 拆分切页、周次和数据更新；添加 `dist/demo/motion.css`。
- [ ] 在 `dist/core/dialogs.js` 加现代版动效开关和可取消拖拽，原版默认同步关闭。
- [ ] 跑浏览器导航/弹窗、课表拖调、日程弹窗及 Node 套件，核对签名与 APK 内置资源。
- [ ] 同步 GitHub Release 和已有网页版。
