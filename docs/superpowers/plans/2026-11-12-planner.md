# 日程规划 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** 让用户按实际日期和分钟安排事情，在课间打开时弹窗，安卓后台用系统通知。
**Architecture:** 页面保存版本化日程定义，浏览器在可见页面检查到期项；安卓同步有界快照，统一领取记录、按下一个到期时间唤醒，去除后台通知与弹窗之间的重复。
**Tech Stack:** ES modules, WebView, Java 17, Android AlarmManager / NotificationManager.
**Spec:** docs/superpowers/specs/2026-11-12-planner-design.md

## Global Constraints

一次性、仅本机、Android 8+、包名与签名保持、既有节次个人安排不动。

## Review Focus

- 保存时已过去的时间应被拒绝；跨天和无效日期分别验证。
- 同一时间多条提醒都送达，同一事件不重复。
- 改期或删除后不能在旧时刻通知，重启可以恢复已登记的未来项。
- 恢复旧备份里的过去项只用于历史；主题包不能分享规划。
- 拒绝通知或精确权限后界面给出真实状态；弹窗关闭后回到原来页面。
