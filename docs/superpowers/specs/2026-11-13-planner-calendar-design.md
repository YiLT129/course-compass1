# 日程周视图与提醒送达

用户在安卓开启通知和准点提醒后划掉最近任务，旧版本到点没收到。无法在用户的 iQOO 上观察厂商清理行为；代码中已定位前台交接没有确认或补发、保存返回时闹钟尚未登记的问题。

- 保留全部旧日程、原课表与原通知类别。日程有独立底栏，七天日历同时可见，按实际日期而非学期；点选日期查看钟点与卡片，左右切周或回今天。下次日程可跳到当天；编辑沿用原表单。
- Android 保存后同步登记最近一个精确系统闹钟和独立普通后备。接收到期时，前台网页先渲染弹窗再确认；没有前台直接交给通知；如果网页没有确认，超时后走系统通知。测试通知总走同一系统闹钟和通知类别，不进日程或备份。
- 权限状态、预计登记和最后一次系统投递分开表示。没有通知权限时仍有应用内弹窗；没有精确权限时 Android 可延后普通提醒。尊重系统勿扰、停止应用与厂商后台限制。
- 网页保留仅页面打开时提醒。不得要求后台常驻、覆盖其他应用、联网账号或使用真实个人课表做公开测试。
