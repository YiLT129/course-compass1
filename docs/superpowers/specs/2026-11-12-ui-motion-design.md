# 课间 UI 动效优化

目标：保留 Telegram 风格的半透明层次，让底栏切页、周次切换和弹窗手势更轻。配色、壁纸、字体密度、七天课表、已有日程与安卓提醒继续沿用。

方案：整页跨淡入会重复绘制和叠加动画；本版用固定玻璃框架、滑动选中条、短幅进入动画，只有需要更新的内容才重画。底层弹窗保持原生 dialog 的焦点与返回行为，外观采用轻量半透明底色，拖动时只变换位置。旧版课表不改变动画设置。系统开启减少动态效果时，取消过渡和回弹延迟。

验收：移动 Chromium、WebKit 检查导航状态与滚动位置、快速切换、拖拽回弹/关闭、嵌套返回、减少动态效果、七天同屏；回归课表拖调和日程弹窗。沿用安卓包名、签名和储存格式。
