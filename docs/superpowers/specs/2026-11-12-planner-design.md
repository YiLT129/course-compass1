# 日程规划与本机提醒

- 在「今日安排」与菜单中打开日程规划。支持新建、编辑和删除一次性日程：标题、日期、分钟、可选备注；按设备时区选择，保存为一个确定的时间点。已有的节次个人安排继续独立使用。
- 提供同一条提醒的两种呈现：前台课间内使用可关闭的弹窗，安卓后台使用系统通知，点击通知打开日程。应用不盖在其他应用上、不联网、不使用账号。
- 方案比较：网页计时器适合前台，关闭后不能可靠运行；系统日历导出依赖外部应用，无法提供课间内弹窗；采用网页前台计时加安卓本机闹钟。安卓使用独立通知类别、尊重通知和勿扰设置，锁屏隐藏私密详情时仅显示通用文字。
- 安卓保留最近一小时内尚未送达且此前成功登记的日程，先领取的一方负责呈现；改期或删除作废旧触发。重启、升级和时间变化重新安排；用户未授予精确闹钟权限时允许系统延后。网页在页面存在并回到前台时可提示近期到期项，关闭后不后台提醒。
- 日程进完整备份，不进主题包或课表分享；导入已过时间的日程不补弹窗。不迁移或修改教务课表、作息和旧个人安排。版本 0.7.0 (20)，Android 8 起，保持包名和现有签名。
