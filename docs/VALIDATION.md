# 0.5.0 验证范围

本版86项数据、适配器和采集器自动检查全数通过，包含课表/成绩解析、旧作息迁移、备份/主题隐私、节次时钟、外观边界与图片明暗分析、单次修改隔离、导入事务/撤回与ICS事件唯一性。具体数量在对应Release中记录。

Chromium与Windows WebKit均验证外观预设与字号/高度/间距、320/390/430/768宽度七天不横向溢出、极限字号内容不裁切、课程配色跨重启、黑/白/复杂壁纸自适应、主题排除课程配色与私人记录。贴纸在同一预览里添加、删除与调整，保留留言/倒数日/链接等私人内容。

单次修改的Chromium原生桥模拟验证：仅所选节次教室改变、停课不作为当前或下一节、快照过滤、其他周不变、今日及胶囊使用实际日期、重新导入变更ID后标记保留、恢复最新教务安排；原始课表始终不改。原版入口也验证同样的有效安排、原生快照、ICS与返回。

胶囊检查包括键盘展开、重启偏好、从其他周打开实际日期详情、同一分钟无多余标题或组件重写、09:05课间/09:15下一节、后台停止更新与回到前台刷新。更新下载与网页切换通过模拟接口检查保存恢复点事务提交后再打开链接或激活更新；保存失败不会假报成功。

数据恢复检查在Chromium与WebKit通过：首次安装不制造空恢复点、旧版本无标记迁移、最近一个恢复点、更新前备份不提前改变已安装版本标记、完整备份携带撤回历史、界面撤回保留私人记录、配额不足保留原始数据及旧撤回状态、中断导入重启恢复、完整恢复失败后的图像/历史/设置回滚。

覆盖升级模拟从真实已交付0.4.1 APK的234个资源开始，在同一个HTTPS应用域名与持久化浏览器资料升级到0.5.0。原始课表、成绩、私人安排、贴纸、旧外观设置和壁纸原图/裁剪图SHA-256全部保留；IndexedDB从2升至3，自动恢复点包含旧照片与私人记录，重复启动不重建。

原版与现代界面共有19个弹层；关闭/返回、短屏、三层返回与取消不改课表回归检查共76个场景。Android标准Gradle构建、原签名验证、启动资源检查及242份内置资源与dist逐字节一致检查用于本版交付。

未连接Android或iPhone真机，未使用真实学校会话验证新版。原生桥模拟不等于真实启动器、分享面板、权限或省电策略验收。Windows WebKit不等于iPhone真机；iOS仍为主屏幕网页，无签名IPA或原生WidgetKit。
