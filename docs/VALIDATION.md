# 0.4.0 验证范围

55项数据、适配器和采集器自动检查通过，覆盖课表/成绩解析、作息迁移、学校来源、预览失败保护，以及完整备份、主题隐私、编辑历史、版本筛选。

Chromium手机视口通过真实拖动、缩放旋转、锁定、撤销重做、重启保存、主题库和导出、完整备份恢复、模拟存储空间不足的回滚、原图保留、海报默认隐私、PNG导出、更新渠道与查询失败保护、下拉/边缘返回、320/390/430/768宽度和模拟原生组件桥的实例隔离。

Windows WebKit26.5也通过同一组交互检查；版本接口和原生桥使用模拟响应，WebKit不等于iPhone真机。离线与服务工作线程更新另在Chromium独立验证。

原版与现代界面共19个弹层通过76个关闭/返回场景；三层返回、反复打开、短屏关闭、取消不改课表均通过。独立检查通过恢复过程中意外关闭后的回滚、等待中的PWA更新按钮、更新后保留本地记录与断网启动。

覆盖升级模拟使用已交付0.3.0 APK中的真实网页资源，同一HTTPS应用域名与持久化浏览器配置，检查课表、成绩、周末偏好及壁纸裁剪图/原图哈希。IndexedDB由v1升级v2，旧Blob图像和新兼容图像记录均可读。

Android标准Gradle构建、启动资源检查、原签名证书验证及233份内置资源与dist逐字节一致检查通过；组件颜色、透明度、边界和内容隔离有独立Java检查。

没有连接Android或iPhone真机，也未使用真实学校会话测试新版登录后同步。浏览器中的原生桥模拟不能代替实际启动器组件或分享面板验收。锁屏实际展示受系统、通知权限、省电策略影响；iOS仍是主屏幕网页，没有原生WidgetKit扩展或已签名IPA。
