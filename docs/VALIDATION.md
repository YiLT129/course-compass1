# 0.3.0验证范围

本地自动检查包含统一课程、作息迁移、采集器、成绩字段和失败保护；新增通用CSV/JSON、挂件配置、学校配置隔离和外校同源模拟。

Chromium手机视口验证挂件添加/真实拖动/重载保存、倒数日、组件风格与内容、通用导入的预览/确认/错误保护、学校切换及原课表保留、320/390/430/768宽度。Windows WebKit26.5也通过同一组完整交互检查，但不等于iPhone真机。新增及原版共15个弹层通过60个关闭/返回场景；编辑挂件时返回会结束编辑。

覆盖升级模拟使用已交付0.2.11 APK的真实网页资源与同一HTTPS本机持久化域名，检查课表、成绩、周末偏好以及壁纸裁剪图/原图哈希。Android构建、证书与资源完整性另行检查。

未连接Android或iPhone真机；未使用真实学校会话验证新学校；没有签名iOS原生安装包或已实现的iOS系统锁屏扩展。Android桌面和锁屏实际展示受桌面启动器、通知权限、省电与系统策略影响。
