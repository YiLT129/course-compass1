# 0.7.0 · 日程规划与本机提醒

- 在「今天 → 日程规划」或菜单新建一次性日程，可选任意日期和分钟，填写标题与可选备注。列表按时间排列，支持编辑、删除和查看历史；原有按节次添加的个人安排仍可使用。
- 到点时，正在使用课间会弹出提醒；Android 退到后台时用独立的「日程提醒」系统通知，点通知打开规划。同一条日程只领取一次，多条到期可以合并通知。权限、横幅和声音可在系统设置调整。
- 允许「闹钟和提醒」后优先按所设时间唤醒；未允许或撤销时保留普通提醒作为后备。重启、覆盖升级或系统时间变化后重新安排未来日程。后台时间和横幅仍受系统、省电和勿扰设置影响；强行停止应用后请重新打开一次。
- 日程在本机保存，包含在完整备份中，不进入主题包或课表海报。恢复备份时，已过期条目只进入历史；改期或删除取消原时间提醒。
- 网页和 iOS 主屏幕网页仅在页面打开时提醒，关闭后不会后台提醒。首次加载后可在离线缓存中继续使用。

Android 8 起，版本 0.7.0（20），沿用包名与原签名。请直接覆盖安装，不要先卸载。

验证：124 项 Node 自动检查及 JVM 提醒队列检查；Chromium 和 Windows WebKit 验证创建、改期、删除、同时到点、关闭弹窗与重开保留；离线网页验证完整恢复、过期记录保护和到点弹窗。标准 Gradle 构建、原签名和 APK 资源核对已完成。安卓后台横幅未在设备上实测。
