# 0.4.1 · 单节课表与当前课程

- 一周课表与今日安排按每个节次单独显示，课程详情展示所点节次的上下课时间；海报同步拆成单节。
- 读取设备当前日期与时间，使用已保存的学校作息判断正在上的课程，并高亮对应节次。查看其他周时不误高亮历史或未来课程。
- 两节连课之间的课间不会继续显示正在上课；下一节开始后自动切换。21:00前后相接的晚课按结束时间不包含边界处理。
- 应用内课程卡片、Android桌面组件和锁屏提示按单节显示当前与下一节。
- 仅拆分显示和时间判断，保留导入的原始排课记录、周次与个人安排；原包名和签名不变，支持覆盖升级。

验证：63项数据与采集自动检查；15项原生时间判断；Chromium及Windows WebKit的课间/下一节/晚课边界、详情、四种宽度、重启保留；76个弹层返回场景；PWA更新、离线及恢复回滚；0.4.0覆盖升级后课表/成绩/周末设置/壁纸原图与裁剪图保留。

未连接Android/iPhone真机或真实学校会话。系统组件与通知刷新仍受权限、省电和启动器策略影响。iOS为主屏幕网页，没有原生WidgetKit或签名IPA。
