# 课间 0.8.1

- 课表表头缩短，周次、日期范围和「本周」排成一行。点击周次可查看当前学期并跳到指定周，教务刷新按钮仍在标题栏。
- 下滑查看晚课时，星期和日期固定在课表顶部。开启周末后，七天在同一屏横向排开。
- 普通课块优先显示课名和教室，较长的教室名可以换行。调课、停课和仅本次调整仍有文字标记。当前课程显示细描边，点开课块可查看完整时间和节次。
- 空间有限时，特别长的课名或教室名可能缩略，详情中可查看全文。已在 Chromium 和 WebKit 检查 320、390、430 像素宽度，尚未在 iQOO 真机验证。
- 安卓包沿用原包名和签名，可在旧版上覆盖安装。本次更新沿用原有课表、作息和外观设置。
